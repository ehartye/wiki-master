## Findings corrected and retained

1. The first project backlog reference still offered unscoped generator examples.
   They now select the project and defer shared-catalog ownership to the canonical
   catalog procedure. The final source was reread.
2. Initialization's manual missing-only branch could be followed by an ambiguous
   instruction to run `init`. The corrected step explicitly chooses either the
   helper or missing-only creation, never both. The custom-template actor exercised
   the safe branch successfully.
3. The first initialization actor recorded only its log in the ledger, omitting
   scaffold files. That run remains **failed**, even though scaffold creation and
   preservation succeeded. Guidance now names the helper's lack of auto-recording,
   explicitly adds each newly written file and verifies the complete ledger.
   `candidate-rerun1-init` demonstrates the correction.
4. The first validation-only actor admitted skipping existing vault instructions;
   that instruction failure is retained. The first simple actor had no explicit
   instruction read in its trace. Its builtin plugin listing cannot prove or
   disprove automatic injection, so that is recorded as an instruction-evidence
   gap, not an invented functional failure. Concrete main-file read instructions
   were reviewed, and both fresh reruns visibly read the actual file before helpers.
