# Skill catalog (names and descriptions only)

- **wiki-maintainer** — Use when asked to repair wiki citations or links, correct factual claims, connect concepts and task maps, apply triage decisions, file an authorized provenance-derived synthesis, or perform a native Obsidian action. Read-only health, freshness, lint and backlog reports belong to wiki-setup; original project documentation belongs to wiki-project.
- **wiki-project** — Use when asked to write or update original wiki project documentation, an overview, as-built architecture, roadmap, backlog item, ADR, guide, diagram, reference or standalone authored note, or list project work by lifecycle. Validation-only requests belong to wiki-setup; retrieved-source synthesis filing belongs to wiki-maintainer.
- **wiki-purge** — Use when explicitly asked to purge or remove a topic and its evidence from the wiki, preview its removal plan, restore a purge, or reconcile an interrupted removal or another machine's copy. Applying a purge requires a reviewed plan and one explicit approval, which states that Obsidian Git publishes the removal on its next run; content repair belongs to wiki-maintainer and diagnostic checks to wiki-setup.
- **wiki-researcher** — Use when asked to discover external sources for the wiki, capture a named URL or saved page, clip PDF, Word, PowerPoint, spreadsheet, GitHub repository or authenticated Confluence evidence, ingest named clippings, or process new/un-ingested clippings. Backlog counts belong to wiki-setup; ordinary web or application work is not a wiki research request.
- **wiki-search** — Use when asked to find wiki pages or passages, look up a title or alias, search captured evidence, trace provenance, or answer a question from the wiki with citations. Read-only retrieval; original project documentation belongs to wiki-project, diagnostics to wiki-setup, and external discovery or ingestion to wiki-researcher.
- **wiki-setup** — Use when asked to initialize a wiki vault, install or configure Obsidian Git, check prerequisites, validate authored paths, report health, freshness, lint or ingest-backlog counts, diagnose search/index/app access failures, troubleshoot capture tools, or recover from a failed setup, a vault written but not refreshed, an Obsidian Git error or a conflict-files-obsidian-git.md file. Reports and diagnosis are read-only; content repairs belong to wiki-maintainer.
