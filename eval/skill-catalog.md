# Skill catalog (names and descriptions only)

- **wiki-init** — Use when asked to initialize or scaffold a new wiki-master vault. Existing-vault health reporting belongs to wiki-maintainer; this is not a migration or repair workflow.
- **wiki-maintainer** — Use when asked to report wiki health, integrity defects, orphan or ingest-backlog counts, review freshness or unsupported claims, repair broken links and citations, connect related concepts, or triage sources needing human attention. Counts and reports are read-only; processing new clippings belongs to wiki-researcher and ordinary application work is not wiki maintenance.
- **wiki-purge** — Use when explicitly asked to purge or remove a topic from the wiki and its evidence, restore a purge, or reconcile an interrupted removal. Requires a reviewed removal plan and explicit publication approval; broken-link repair belongs to wiki-maintainer.
- **wiki-researcher** — Use when asked to discover external sources for the wiki, capture a named URL or file as evidence, clip PDF, Word, PowerPoint, spreadsheet, GitHub repository or authenticated Confluence sources, ingest named existing clippings, or process new/un-ingested clippings. A backlog count is maintainer reporting; ordinary web or application work is not a wiki research request.
- **wiki-user** — Find wiki pages or passages, answer questions from the wiki with citations, write or update original wiki project documentation, guides, ADRs and backlog items, or perform a requested Obsidian app action. Ordinary application work does not activate wiki operations; discovering external sources and ingesting clippings belong to wiki-researcher.
